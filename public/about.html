About DeryCode AI Search Engine

DeryCode AI is a privacy-focused search engine that aggregates results from 22 data sources across the web. It offers 10 search modes — from web and image search to academic papers, deep web, and AI-powered answers — all with zero tracking, zero ads, and zero cookies.

Mission

To give users in Africa and worldwide a powerful, private alternative to ad-funded search engines. No data collection. No behavioral profiling. Just search results.

Search Modes

  • AI Answers — AI-generated summaries from multiple sources
  • Web Search — DuckDuckGo + Google results
  • Image Search — Web image aggregation
  • News Search — Google News results
  • Code Search — Code snippets and documentation
  • Derick AI — Conversational AI assistant
  • Book Search — Google Books + Project Gutenberg
  • Maps — Location search via DeryMap
  • Deep Web — Wikidata, CORE, World Bank, CrossRef, Ahmia, Internet Archive
  • Videos — Video search across platforms

Data Sources (22)

DuckDuckGo, Google, Wikipedia, Google Books, Google News, Google Scholar, PubMed, Project Gutenberg, Wikidata, CORE Research, World Bank Data, CrossRef DOIs, Internet Archive, Ahmia (.onion index), and more — all queried in real-time.

Key Features

  • AI-powered answer generation from search results
  • Wikipedia knowledge panels for entities and topics
  • Academic paper search (PubMed, Scholar, CrossRef)
  • Multi-language support: English, Swahili, Luganda, Runyankole, Luo, Ateso
  • Voice search and autocomplete suggestions
  • Search history (stored locally only — never on servers)
  • Progressive Web App (installable, works offline)
  • No tracking, no ads, no cookies, no analytics
